Security and compatibility

Production safeguards for the next implementation stage.

  • Use the original JSON export as the initial dataset.
  • Keep this app's browser storage namespace separate from production FinTrack.
  • Never store passwords in the JSON backup.
  • Use a development Firebase project for initial auth/sync integration.
  • Validate import/export, transaction IDs, budget keys, deleted-record tombstones and custom settings before syncing.
  • Do not enable any cloud write until the exact original sync behavior is ported and regression-tested.
